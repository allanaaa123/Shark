# Shark：Android 桌面海洋寵物

原生 Kotlin App。可新增雙髻鯊、鯨鯊、殺人鯨（虎鯨），透明懸浮顯示於其他 App 上方。

- Android 8.0（API 26）以上。
- 三種寵物合計最多 10 隻，每隻獨立設定尺寸與速度，重新開啟後保留設定。
- 自然變速、游出畫面後轉回，預覽與桌面使用相同導航及動畫播放器。
- 雙髻鯊有直游／左右轉動畫；鯨鯊與殺人鯨使用已確認的循環游泳動畫，依導航轉向。

## 使用手機取得 APK

1. 開啟本專案 Pull Request 的 Checks，進入成功的 **Build Android APK** 執行紀錄。
2. 在 **Artifacts** 下載 **SharkOverlay-APK**，解壓縮後安裝其中的 debug APK。
3. 開啟 App，按「＋ 新增鯊魚／鯨魚」，選擇物種並調整每隻的尺寸及游速。
4. 按「啟動 / 更新桌面寵物」，授予「顯示在其他應用程式上層」權限，返回後再次啟動。
5. 修改設定後再次按「啟動 / 更新桌面寵物」套用到桌面。可由 App 或通知停止全部寵物。

PR 無須合併即可下載測試版。GitHub Actions 在 PR、main 推送及手動執行時進行 JVM 測試、Android lint 與 APK 編譯。實機流暢度、觸控穿透、不同 Android 系統及耗電需另外驗證。

## 開發說明

動畫素材、記憶體使用、Android 相容播放及再製方式見 [動畫整合說明](docs/animation-integration.md)。
鯨鯊與殺人鯨已由 8 個原始姿勢動態補幀至約 24 FPS（每幀 42ms，與雙髻鯊一致），尚未製作獨立的左右轉片段。

懸浮視窗使用 `FLAG_NOT_TOUCHABLE`；未提供拖曳或點擊互動。系統安全畫面、Android 懸浮視窗安全規則與廠商省電設定可能影響顯示或背景運作。
