# 桌面海洋寵物

Android 8 以上的透明桌面寵物，共用單一不可觸控視窗，在其他 App 上方游動。

可選 9 種：雙髻鯊、鯨鯊、殺人鯨（虎鯨）、大白鯊、虎鯊、尖吻鯖鯊、長尾鯊、豹紋鯊、遠洋白鰭鯊。總上限為 50 隻，每隻獨立設定大小和游速，保存後重新啟動仍會保留。

魚群互動提供四段單選：關閉、自然水族箱（避讓／並游／大小魚禮讓）、活潑寵物（避讓／好奇跟隨／短暫追逐）、海洋魚群（避讓／尾流跟隨／鬆散結群）。切換立即套用至預覽和桌面並保存，不重置位置。每隻同時最多一個主要互動對象；互動有時間限制、冷卻及平滑轉向／變速，仍允許交錯重疊，離屏回游優先。鄰近判斷使用移動前的共同快照，以 10Hz 更新，輸出跟隨螢幕刷新平滑變化。

清單上方的「隨機新增 N 隻」可輸入數量，一次從 9 種物種中隨機挑選並加入（允許重複），保留原有寵物。對話框顯示剩餘名額，拒絕無效或超過 50 隻總上限的數量，整批加入後統一保存及更新預覽。

設定頁提供即時預覽、啟動／更新與停止。水中特效有關閉／輕柔／明顯三段，立即套用到預覽與桌面並保存；包含淡藍尾流、轉彎水紋，以及轉彎時增加的氣泡。

雙髻鯊使用既有圖集和網格擺尾；其餘物種以共用透明姿勢、連續形變與各自的擺尾節奏游動。轉彎時身體先彎、尾部延遲跟上，氣泡及尾流跟隨尾部。長尾鯊與豹紋鯊保留完整長尾輪廓。

素材依物種共用，增加魚隻不會複製圖片。超過 10 隻時逐步降低每隻的特效取樣與排放密度，仍保留轉彎比直游更多氣泡。連續網格預先計算係數，桌面更新跟隨螢幕刷新，熄屏暫停。

首次啟動需允許「顯示在其他應用程式上層」。Android 12 以上依系統觸控遮擋上限調整整個懸浮視窗的不透明度；安全性 App 仍可能限制被遮擋的操作，可從通知停止寵物。

建置與檢查：

```sh
gradle testDebugUnitTest lintDebug assembleDebug
python tools/check_species_assets.py
```

圖片檢查需 Pillow。GitHub Actions 成功後，可從該次執行的 `SharkOverlay-APK` artifact 下載 APK 壓縮檔。

50 隻混合物種的狀態、網格和特效池有單元測試；實際幀率、耗電與發熱仍需依手機實測。
