# 桌面海洋寵物

Android 8 以上的透明桌面寵物，共用單一不可觸控視窗，在其他 App 上方游動。

可選 14 種：雙髻鯊、鯨鯊、殺人鯨（虎鯨）、大白鯊、虎鯊、尖吻鯖鯊、長尾鯊、豹紋鯊、遠洋白鰭鯊，以及深海藍點魟魚、暖金藍點魟、黑金星斑鷹魟、銀灰鑽石魟、深藍蝠鱝。總上限為 50 隻，每隻獨立設定大小和游速，保存後重新啟動仍會保留。

並游、跟隨、追逐與群游的觸發更頻繁、持續更久、冷卻更短；避讓依相對速度預測交會風險，不因單純靠近就一律中斷互動。遇到約 1.5 倍或 2 倍以上的魚時，小魚會更早注意並更積極禮讓；安全的並行、擦身及尾流跟隨仍可繼續。

魚群互動提供四段單選：關閉、自然水族箱（避讓／並游／大小魚禮讓）、活潑寵物（避讓／好奇跟隨／短暫追逐）、海洋魚群（避讓／尾流跟隨／鬆散結群）。切換立即套用至預覽和桌面並保存，不重置位置。每隻同時最多一個主要互動對象；互動有時間限制、冷卻及平滑轉向／變速，仍允許交錯重疊，離屏回游優先。鄰近判斷使用移動前的共同快照，以 10Hz 更新，輸出跟隨螢幕刷新平滑變化。

清單上方的「隨機新增 N 隻」可輸入數量，一次從 14 種物種中隨機挑選並加入（允許重複），保留原有寵物。對話框顯示剩餘名額，拒絕無效或超過 50 隻總上限的數量，整批加入後統一保存及更新預覽。可選「固定：大小、速度皆為 100%」或「常態分佈」；後者以 100% 為中心，大小標準差 25%、速度標準差 20%，兩者獨立抽樣，超出大小 30–200%／速度 20–200% 時重抽。記住最後成功新增時使用的選項，單批平均不保證剛好 100%。

「搖動驚嚇」開關預設關閉，選擇會保存並立即套用至預覽與桌面。開啟後，短時間內兩次明顯晃動會讓魚轉向散開、約 2.2 秒短暫加速（最高約額外 1.75 倍），再平順恢復；觸發間隔至少 4 秒，受驚時暫停社交配對但仍優先離屏回游。關閉、熄屏、停止服務時停止相關感測器，預覽只在海洋頁前景偵測；缺少加速度感測器的裝置會停用此開關，不新增權限。

介面分為「海洋／生物／設定」三頁。海洋頁提供即時預覽、運行狀態、啟動／停止與新增入口。生物頁用縮圖卡片管理，可依鯊魚／魟魚／鯨豚分類、搜尋，長按進入多選批次調整或刪除；刪除後 10 秒內可復原。點擊卡片開啟底部編輯面板，大小與速度立即保存套用；只更動實際調整的欄位。新增可指定物種或隨機物種，輸入數量並選固定值／常態分佈。

每隻生物有穩定 ID，舊版資料首次開啟自動遷移並保留物種、大小、速度及順序。更新現有生物會保留桌面位置及游動狀態，新增只建立新增的生物。

設定頁集中水中特效、魚群互動和搖動驚嚇。水中特效有關閉／輕柔／明顯三段，立即套用到預覽與桌面並保存；包含淡藍尾流、轉彎水紋，以及轉彎時增加的氣泡。

雙髻鯊使用既有圖集和網格擺尾；其餘物種以共用透明姿勢、連續形變與各自的擺尾節奏游動。轉彎時身體先彎、尾部延遲跟上，氣泡及尾流跟隨尾部。長尾鯊與豹紋鯊保留完整長尾輪廓。

五種魟魚使用已審核的透明姿勢與各自連續鰭面網格，頭部穩定、胸鰭波動、尾部延遲；轉彎加上非對稱鰭面與身體彎曲，深藍蝠鱝節奏較慢。尾流跟隨各自的尾尖。

素材依物種共用，增加魚隻不會複製圖片。超過 10 隻時逐步降低每隻的特效取樣與排放密度，仍保留轉彎比直游更多氣泡。連續網格預先計算係數，桌面更新跟隨螢幕刷新，熄屏暫停。

首次啟動需允許「顯示在其他應用程式上層」。Android 12 以上依系統觸控遮擋上限調整整個懸浮視窗的不透明度；安全性 App 仍可能限制被遮擋的操作，可從通知停止寵物。

建置與檢查：

```sh
gradle testDebugUnitTest lintDebug assembleDebug
python tools/check_species_assets.py
```

圖片檢查需 Pillow。GitHub Actions 成功後，可從該次執行的 `SharkOverlay-APK` artifact 下載 APK 壓縮檔。

50 隻混合物種的狀態、網格和特效池有單元測試；實際幀率、耗電與發熱仍需依手機實測。
